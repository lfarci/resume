# Write Resume Copy

Use for resume summaries, bullets, skills, certifications, and project copy.
`docs/` is canonical and `AGENTS.md` is higher priority than this skill.

## Copy rules

- Start from documented facts and preserve their scope, chronology, official
  titles, uncertainty, and ownership.
- Prefer precise actions and outcomes over duty lists or technology dumps.
- Quantitative evidence is useful when it exists in the canonical notes. A
  strong bullet does not require a number.
- Never manufacture, infer, extrapolate, or conservatively estimate a metric.
  If a valuable metric is missing, ask the user; otherwise use the strongest
  accurate qualitative outcome.
- Never add team sizes, budgets, users, dates, percentages, technologies,
  credentials, or sole ownership without verified support.
- Add job-relevant terms only when they accurately describe documented work.

When revising copy, show the original and proposed wording, explain the
evidence used, and identify any claim that needs clarification.

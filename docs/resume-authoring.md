> Cloud & AI Engineer | GitHub Actions, Azure & GitHub Copilot

`AI Engineer` can imply traditional machine-learning/AI engineering expertise that is not currently Logan's primary background.

> **Software & Cloud Engineer | Azure, GitHub Actions & GitHub Copilot**

## Tailored Resume Rules

When adapting the master resume to a job description:

1. Keep factual chronology unchanged.
2. Never invent technologies to match the offer.
3. Reorder existing evidence instead of adding unsupported claims.
4. Change the headline and summary according to the target.
5. Reorder skills.
6. Select the most relevant professional bullets.
7. Add at most one or two relevant projects if they strengthen the application.
8. Keep strong metrics where relevant.
9. Prefer outcomes over technology lists.
10. Maintain ATS-readable formatting.
11. Preserve team-vs-individual ownership.
12. Ask for clarification before introducing unsupported facts.

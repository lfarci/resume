# Resume fonts

The resume embeds the same font families used by the personal website:

- `Manrope-SemiBold.ttf` and `Manrope-Bold.ttf` are used for the name, headline,
  and section headings.
- `NotoSans-Regular.ttf` and `NotoSans-Bold.ttf` are used for all body text.

The files are licensed under the SIL Open Font License 1.1; its full text is in
[`OFL-1.1.txt`](./OFL-1.1.txt). The Noto Sans files are static instances of the
Google Fonts Noto Sans variable font. Embedding the files keeps local and CI
PDF output consistent and preserves selectable text for ATS parsing.
